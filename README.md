# دعوة زفاف نسرين ومنصور

دعوة إلكترونية تفاعلية: صدفة ولؤلؤة ثلاثية الأبعاد ← الأسماء وصورة العروسين ← الترحيب والآية ←
التقويم والعدّاد والمكان ← الملاحظات ← بطاقة «موعدنا» ← تأكيد الحضور ← الختام.

الموقع منشور على Vercel ويتحدّث تلقائيًا مع كل تعديل على فرع `main`:
https://shell-wedding-invetation-lac.vercel.app

## التشغيل محليًا
```
npm install
npm run dev     # ثم افتحي الرابط الظاهر (يعمل على الهاتف عبر الشبكة المحلية)
npm run build   # نسخة النشر في مجلد dist
```

## كل النصوص والقيم — ملف واحد: `src/config/wedding.js`
- الأسماء والعنوان الفرعي.
- `dateTime`: موعد الحفل بتوقيت ليبيا، مثل `'2026-12-25T20:00:00+02:00'`، و`durationHours` مدة الحفل (لملف التقويم).
- `venueName` و`venueCity` و`mapsUrl`: اسم الصالة والمدينة ورابط الخريطة (من Google Maps: مشاركة ← نسخ الرابط).
- `welcome` و`verse`: رسالة الترحيب والآية ومرجعها.
- `notes`: الملاحظات الخاصة.
- `rsvp.maxCompanions`: الحد الأقصى للمرافقين (لو تغيّر، غيّريه أيضًا في `firestore.rules`).
- `rsvp.deadline`: آخر موعد لتأكيد الحضور بصيغة `'2026-12-15'` (اتركيه فارغًا لإخفاء السطر).
- `thanks` و`afterEvent`: رسالة الشكر، والرسالة التي تظهر مكان العدّاد بعد يوم الحفل.
- `music`: الأغنية (انظري الأسفل).
- `siteUrl`: رابط الموقع المنشور (تُبنى منه صورة المعاينة في واتساب).

عنوان الصفحة ووصفها في معاينة الرابط وملف التقويم `wedding.ics` (لأجهزة آيفون) تُنشأ تلقائيًا من هذا الملف وقت البناء.

## الصور — مجلد `public/assets`
- `hall-portrait.webp`: خلفية القاعة للجوال (طولية وعالية الدقة)، و`hall.webp`: نفس القاعة بالعرض للشاشات الكبيرة والافتتاحية.
- `couples.webp`: صورة العروسين بخلفية شفافة (النسبة 2:3).
- `logo.webp`: الشعار بخلفية شفافة، ويُلوَّن ذهبيًا تلقائيًا.
- نقطة تركيز الزوم على الفستان: `transform-origin:33% 68%` في CSS و`0.33/0.68` في `Story.jsx`.

ملفات في `public/` مباشرة: `og-image.jpg` (صورة المعاينة 1200×630)، `favicon.png` و`apple-touch-icon.png` (أيقونة الموقع).

## الموسيقى
ضعي ملف الأغنية في `public/assets/music/love-story.mp3` (يُفضّل مقطعًا جاهزًا 1–2 دقيقة بجودة 128kbps).
تبدأ الأغنية بهدوء عند الضغط على اللؤلؤة، وتتكرر بنعومة، وتتوقف مؤقتًا لما الضيف يطلع من الصفحة.
زر الصوت يبقى ظاهرًا أعلى الشاشة طوال الدعوة. لو الملف غير موجود، الدعوة تعمل عادي ويختفي زر الصوت بعد الافتتاحية.
لو الملف هو الأغنية كاملة، حدّدي ثانية البداية في `music.start`.

ملاحظة: المستودع عام، يعني أي ملف داخله (ومنها الأغنية) يقدر أي شخص يحمّله. لو تبين، حوّلي المستودع إلى Private من
إعدادات GitHub، وVercel يستمر في النشر عادي.

## Firebase وتأكيد الحضور
كل رد يُحفظ في مجموعة Firestore باسم `rsvps`: الاسم، الحضور، عدد المرافقين، العدد الإجمالي، ووقت الإرسال.
كل جهاز يتذكّر ردّه، فـ«تعديل الرد» يحدّث نفس الرد بدل ما يكرره، ويوجد خيار «إرسال رد باسم شخص آخر» لو الجهاز مشترك.
تُحمَّل مكتبة Firebase فقط عند الوصول لنموذج الرد، حتى تفتح الدعوة أسرع.

**قواعد الحماية (مهم):** افتحي Firebase Console ← Firestore Database ← Rules، والصقي محتوى ملف `firestore.rules`، ثم Publish.
القواعد تسمح للضيف بإرسال ردّه أو تعديله فقط، وتمنع قراءة الردود أو حذفها من الموقع العام. أنتم تشوفون الردود من لوحة Firebase.
(أو من الطرفية: `npx firebase-tools deploy --only firestore:rules --project wedding-invitations-181a3`)

إعدادات Firebase للويب ليست سرّية. لو تبين تستخدمي مشروعًا آخر، انسخي `.env.example` إلى `.env.local` وضعي إعداداته،
وفي Vercel أضيفي نفس المتغيرات من **Project Settings ← Environment Variables**.
