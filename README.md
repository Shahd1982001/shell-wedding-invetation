# دعوة زفاف نسرين ومنصور (نسخة تجريبية)

## التشغيل
```
npm install
npm run dev     # ثم افتحي الرابط الظاهر (يعمل على الهاتف عبر الشبكة المحلية)
npm run build   # للنشر (مثلاً Vercel)
```

## القيم التجريبية القابلة للتعديل — ملف واحد: `src/config/wedding.js`
الأسماء، التاريخ والوقت (`dateTime`)، اسم الصالة، المدينة، رابط الخرائط (`mapsUrl`)، رسالة الترحيب،
الآية ومرجعها (يُرجى مراجعتها على المصحف)، الملاحظات الخاصة، الحد الأقصى للمرافقين، رسالة الشكر.

## استبدال الصور — مجلد `public/assets`
- `hall.jpg`: خلفية القاعة الثابتة (يفضّل نسخة أعلى دقة، مثلاً 1600×2400 للهاتف).
- `couple.jpg`: صورة العروسين (نفس الاسم والنسبة تقريبًا 425×510؛ إن تغيّرت النسبة عدّلي `aspect-ratio` في `.zoomwrap`).
- `logo.png`: الشعار (شفاف الخلفية). يظهر بلون عاجي فوق الصورة.
- نقطة تركيز الزوم على الفستان: `transform-origin:33% 68%` في CSS و`0.33/0.68` في `Story.jsx`، وخط انقسام الستارة `67%/33%` في `.half`.
